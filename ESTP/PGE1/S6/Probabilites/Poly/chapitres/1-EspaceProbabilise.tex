\section{Pourquoi faire des probabilités en ingénierie ?}

Sur un chantier ou dans un laboratoire, on prend des décisions en présence d'incertitude :
\begin{itemize}
    \item un lot de béton est-il conforme ?
    \item combien de pièces non conformes peut-on attendre sur une livraison ?
    \item quelle est la probabilité d'avoir trois jours favorables au coulage ?
    \item une mesure observée est-elle compatible avec le cahier des charges ?
\end{itemize}

Les probabilités servent à \textbf{transformer une situation incertaine en modèle calculable}. Le but n'est pas de décrire toute la réalité, mais de garder ce qui est utile pour la décision.

\begin{Rmq}
Dans ce cours, on suit toujours le même raisonnement :
\begin{center}
\textbf{situation de terrain} $\rightarrow$ \textbf{modèle} $\rightarrow$ \textbf{calcul} $\rightarrow$ \textbf{interprétation} $\rightarrow$ \textbf{décision}
\end{center}
\end{Rmq}

\section{Univers, événements et probabilité}

\begin{Def} 
\leavevmode \\
L'\textbf{univers} $\Omega$ est l'ensemble de tous les résultats possibles d'une expérience aléatoire.
\end{Def}

\begin{Def}
Un \textbf{événement} est une question à laquelle on peut répondre par \og oui \fg{} ou \og non \fg{}. Mathématiquement, c'est une partie de l'univers.
\end{Def}

\begin{Ex}
\textbf{Contrôle d'une éprouvette de béton}

On mesure la résistance à 28 jours d'une éprouvette prélevée sur chantier.
\begin{itemize}
    \item Si l'on s'intéresse à la résistance en MPa, on peut prendre $\Omega = [0,+\infty[$.
    \item L'événement $A = \{\omega \geq 25\}$ signifie : \og l'éprouvette atteint au moins $25$ MPa \fg.
    \item L'événement $B = \{24 \leq \omega \leq 28\}$ signifie : \og la résistance est dans la plage attendue \fg.
\end{itemize}
\end{Ex}

\begin{Def}
Une \textbf{probabilité} $\mathbb{P}$ associe à chaque événement un nombre entre $0$ et $1$.
\end{Def}

\begin{Prop}
Pour tout événement $A$ :
\begin{itemize}
    \item $0 \leq \mathbb{P}(A) \leq 1$  
    \item $\mathbb{P}(\Omega)=1$  
    \item $\mathbb{P}(\varnothing)=0$.
\end{itemize}
\end{Prop}


\section{Opérations sur les événements}

Si $A$ et $B$ sont deux événements :
\begin{itemize}
    \item $A \cup B$ signifie \og $A$ ou $B$ \fg{}  
    \item $A \cap B$ signifie \og $A$ et $B$ \fg{}  
    \item $\overline{A}$ signifie \og non $A$ \fg{}  
    \item $A \setminus B$ signifie \og $A$ mais pas $B$ \fg.
\end{itemize}

\begin{Ex}
\textbf{Lecture en langage chantier}

On note :
\begin{itemize}
    \item $A$ : \og la résistance dépasse $25$ MPa \fg  
    \item $B$ : \og il pleut le jour du coulage \fg.
\end{itemize}

Alors :
\begin{itemize}
    \item $A \cap B$ : le béton est suffisamment résistant \textbf{et} il pleut le jour du coulage  
    \item $A \cup B$ : au moins une des deux affirmations est vraie  
    \item $\overline{B}$ : il ne pleut pas le jour du coulage.
\end{itemize}
\end{Ex}

\section{Variable aléatoire : ce que l'on mesure}

\begin{Def}
Une \textbf{variable aléatoire} $X$ est une grandeur numérique qui dépend du résultat de l'expérience.
\end{Def}

\begin{Rmq}
Dans la pratique, une variable aléatoire est souvent la quantité qu'on observe ou qu'on calcule :
\begin{itemize}
    \item résistance d'une éprouvette  
    \item nombre de pièces non conformes  
    \item temps d'attente d'une toupie  
    \item hauteur de pluie d'une journée.
\end{itemize}
\end{Rmq}

\begin{Def}
Une variable aléatoire est dite \textbf{discrète} si elle prend des valeurs isolées, en nombre fini ou dénombrable.

Elle est dite \textbf{continue} si elle peut prendre toutes les valeurs d'un intervalle.
\end{Def}

\begin{Ex}
\textbf{Exemples typiques}
\begin{itemize}
    \item Nombre de pieux défectueux dans un lot de $20$ pieux : variable discrète.
    \item Nombre de jours de pluie dans un mois : variable discrète.
    \item Résistance d'une éprouvette en MPa : variable continue.
    \item Longueur d'une fissure en mm : variable continue.
\end{itemize}
\end{Ex}

\section{Modéliser une situation concrète}

\begin{Meth}
Pour traduire un énoncé en langage probabiliste, on peut suivre les quatre étapes suivantes :
\begin{enumerate}
    \item Identifier l'expérience aléatoire : que regarde-t-on exactement ?
    \item Choisir la variable ou les événements utiles à la décision.
    \item Préciser si la grandeur est discrète ou continue.
    \item Écrire en français la question que l'on veut calculer.
\end{enumerate}
\end{Meth}

\begin{Ex}
\textbf{Météo et planification de chantier}

Un chef de chantier veut couler une dalle un jour sans pluie forte.
\begin{itemize}
    \item Expérience : observer la météo du jour choisi.
    \item Variable : $X =$ nombre de jours de pluie sur une période donnée.
    \item Événement utile : $A =$ \og le jour choisi est favorable au coulage \fg.
    \item Question typique : calculer $\mathbb{P}(A)$ ou la probabilité d'avoir plusieurs jours favorables successifs.
\end{itemize}
\end{Ex}

\section{Erreurs fréquentes}

\begin{itemize}
    \item Confondre un \textbf{résultat observé} avec un \textbf{événement}.
    \item Choisir un univers trop compliqué pour la question posée.
    \item Oublier d'écrire l'événement en français avant de manipuler des formules.
    \item Confondre une grandeur discrète avec une grandeur continue.
\end{itemize}

\section{Ce qu'il faut savoir faire}

À la fin de ce chapitre, il faut savoir :
\begin{itemize}
    \item proposer un univers simple et pertinent  
    \item définir des événements utiles à la décision  
    \item manipuler union, intersection et complémentaire  
    \item reconnaître si une variable est discrète ou continue  
    \item traduire un contexte d'ingénierie en question probabiliste.
\end{itemize}
